# java-menu

# 📌 요구사항 요약
코치별로 한 주 평일의 점심 메뉴를 추천해주는 서비스
<br/>

#### 플로우
1. 시작 문구 출력
2. 각 코치 이름 입력 받기
3. 각 코치별로 못 먹는 메뉴 입력 받기
4. 요일별 카테고리 무작위 결정 (같은 건 최대 2회까지)
5. 코치마다 못 먹는 음식 제외하고 메뉴 추천
6. 추천 결과 (구분, 카테고리, 코치별 음식)
7. 종료 문구 출력

## ⭐ 특이 사항
- [ ] 같은 카테고리(일식/한식/중식/아시안/양식)는 최대 2회까지 가능
- [ ] 정해진 메뉴 등록해야 함
- [ ] 음식이 중복되지 않도록 해야함
- [ ] 코치마다 못 먹는 음식은 추출에서 제외해야 함
<br/>

# 📝 구현할 기능 목록
## 1. 서비스 시작
### a. 시작 문구 출력
- [x] `점심 메뉴 추천을 시작합니다.` + 밑에 빈 줄 추가 출력
### b. 각 코치 이름 입력 받기
- 조건
- [x] 코치 이름 입력 요구 문구 출력
- [x] 코치 이름은 최소 2글자에서 최대 4글자
- [x] 코치 수는 최소 2명에서 최대 5명까지
- [x] `,`로 구분되어 입력된다
- [x] 입력 이후 빈 줄 추가
- 예외
- [x] 한글이 아닌 문자가 들어올 경우
- [x] 코치 수가 2명 이상 5명 이하가 아닌 경우
- [x] 입력 형식이 맞지 않는 경우
- [x] 코치 이름이 중복된 경우
### c. 코치마다 못 먹는 메뉴 입력 받기
- 조건
- [ ] 코치의 이름과 함께 입력 요구 문구 출력
- [ ] 못 먹는 메뉴가 없으면 빈 값
- [ ] 2개 이하의 메뉴가 들어온다 
- [ ] `,`로 구분되어 입력된다
- [ ] 각 입력 이후 빈 줄 추가
- [ ] `,`를 기준으로 메뉴를 추출해 코치 이름을 key로 map에 저장한다
- 예외
- [ ] 한글이 아닌 문자가 들어올 경우
- [ ] 2개 이하가 아닌 경우
- [ ] 입력 형식이 맞지 않는 경우 (빈 값 제외)
## 2. 메뉴 추천
### a. 기본 카테고리 및 메뉴 등록
- [ ] 카테고리별로 정해진 메뉴를 등록한다
- [ ] 카테고리를 key로 map에 저장할 때, 메뉴 목록을 `List<String>` 형태로 저장한다.
### b. 요일별 메뉴 카테고리 결정
- 조건
- [ ] 같은 카테고리는 최대 2회까지만 가능
- [ ] 추천할 카테고리는 `camp.nextstep.edu.missionutils`에서 제공하는 `Randoms.pickNumberInRange()`에서 생성한 값을 활용
- [ ] `Randoms.pickNumberInRange()`의 결과가 1이면 일식, 2면 한식, 3이면 중식, 4면 아시안, 5면 양식을 추천
- [ ] 추천할 수 없는 카테고리인 경우 다시 `Randoms.pickNumberInRange()`를 통해 임의의 값을 생성
### c. 요일마다 각 코치 메뉴 추천
- 조건
- [ ] 각 코치에게 중복되지 않는 메뉴를 추천해야 한다
- [ ] 못 먹는 메뉴를 제외하고 추천해야 한다
- [ ] 추천할 메뉴는 정해진 카테고리에 있는 메뉴를 `camp.nextstep.edu.missionutils`에서 제공하는 `Randoms.shuffle()`을 통해 임의의 순서로 섞은 후, 첫 번째 값을 사용해야 한다.
- [ ] 카테고리에 포함되는 메뉴 목록을 `List<String>` 형태로 준비한다.
- [ ] 코치에게 추천할 메뉴를 정할 때 이미 추천한 메뉴, 먹지 못하는 메뉴도 포함된 리스트를 전달해야 한다.
- [ ] 추천할 수 없는 메뉴인 경우 다시 섞은 후 첫 번째 값을 사용해야 한다.
## 3. 서비스 종료
### a. 메뉴 추천 결과 출력
- 조건
- [ ] 메뉴 추천 결과 기본 문구 출력
- [ ] 각 시작은 `[`로 시작해 공백으로 띄워져 `|`로 나눠지고, 마지막은 `]`로 끝난다.
- [ ] 첫 줄은 요일 구분
- [ ] 두 번째 줄은 카테고리
- [ ] 아래부터는 각 코치별 추천 메뉴 출력
- [ ] 결과 끝에 빈 줄 추가 출력
### b. 추천 완료 문구 출력
- [ ] 서비스 종료 문구 출력

# 💡 스스로 판단한 규칙
- [ ] 못 먹는 메뉴 입력에 없는 메뉴를 입력하더라도 허용한다.
- [ ] 코치 이름은 한글로만 이루어져있어야 한다.
- [ ] 앞뒤 공백이 있더라도 허용한다.
- [ ] 코치 이름이 중복된 경우 다시 입력 받는다.

# ⚠️ 프로그래밍 요구사항
- [ ] 예외 상황 시 에러 문구를 출력해야 한다. 단, 에러 문구는 "[ERROR]"로 시작해야 한다.
- [ ] 프로그램 구현이 완료되면 ApplicationTest의 모든 테스트가 성공해야 한다.
- [ ] indent(인덴트, 들여쓰기) depth를 3이 넘지 않도록 구현한다. 2까지만 허용한다.
- [ ] 3항 연산자를 쓰지 않는다.
- [ ] 함수(또는 메서드)의 길이가 15라인을 넘어가지 않도록 구현한다.
- [ ] else 예약어를 쓰지 않는다.
